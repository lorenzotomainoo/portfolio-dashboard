Collegare / aggiornare il foglio Google

⚠️ Se avevi GIÀ lo script vecchio: sostituisci il codice e poi pubblica una NUOVA VERSIONE (punto 4). Senza quel passaggio continua a girare il vecchio codice!
  1. Apri sheets.google.com → il tuo foglio (o creane uno vuoto).
  2. Menu Estensioni → Apps Script: cancella TUTTO il contenuto e incolla il codice qui sotto. Salva.
  3. Nuovo script: Distribuisci → Nuova implementazione → Applicazione Web → Esegui come: me → Accesso: chiunque → Autorizza.
  4. Script già esistente: Distribuisci → Gestisci implementazioni → ✏️ Modifica → Versione: Nuova versione → Distribuisci.
  5. I dati vengono scritti sul primo foglio (Foglio1) con colonne etichettate: data, tipo, dettaglio, lingua, dispositivo, sistema, browser, paese, città, provenienza. Il vecchio tab "events" (se c'era) continua a essere letto: puoi cancellarlo dopo aver verificato.
  6. Torna qui e premi INVIA EVENTO TEST: se arriva sul foglio, tutto il percorso funziona.
